# Image Analysis - MEV Pore Quantification
 
Este repositório contém scripts para análise automática de porosidade e tamanho médio de poros em imagens obtidas por Microscopia Eletrônica de Varredura (MEV).
 
## 📌 Funcionalidades
- Conversão da imagem para escala de cinza
- Threshold automático (Otsu)
- Segmentação dos poros
- Cálculo da porosidade
- Cálculo do tamanho médio dos poros
- Leitura opcional de escala para conversão para micrômetros
